# Customer Segmentation & Behavior Analysis

## Project Overview

This project segments customers based on their purchasing behavior using Machine Learning and Power BI.

The project uses K-Means clustering to identify different customer groups and analyzes their purchasing patterns, sales, profit, frequency, recency, and quantity.

## Objectives

- Segment customers based on purchasing behavior
- Analyze customer purchase patterns
- Identify high-value and low-value customer groups
- Visualize customer segments
- Generate useful business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Power BI
- K-Means Clustering

## Features Used

- Recency
- Frequency
- Monetary Value
- Profit
- Quantity

## Machine Learning

K-Means clustering was used to group customers with similar purchasing behavior.

The number of clusters was evaluated using the Silhouette Score.

## Dashboard

The Power BI dashboard includes:

- Total Customers
- Total Sales
- Total Profit
- Total Quantity
- Customer Segment Distribution
- Sales by Segment
- Profit Analysis
- Customer Purchase Analysis
- Interactive Filters

## Project Workflow

Dataset → Data Cleaning → Feature Engineering → Scaling → K-Means Clustering → Customer Segmentation → Power BI Dashboard → Business Insights

## Output

The project provides customer segments that can help businesses understand customer behavior and develop targeted marketing strategies.
